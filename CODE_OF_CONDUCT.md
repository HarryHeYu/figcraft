# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/)
version 2.1 ([full text](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)),
condensed below for a small project. The linked full text prevails where this
summary is ambiguous.

## Our standard

Be respectful and constructive. Harassment, discriminatory language, personal
attacks, publishing others' private information, and other unprofessional
conduct are not tolerated in issues, pull requests, code review, or any other
project space.

## Scope

Applies within project spaces on GitHub, and when an individual officially
represents the project elsewhere.

## Enforcement

Report violations privately to the maintainer
([@HarryHeYu](https://github.com/HarryHeYu)) — e.g. via the private
vulnerability/contact channel described in [SECURITY.md](SECURITY.md); a
dedicated conduct contact may replace this. Reports are handled
confidentially.

Maintainers may remove, edit, or reject contributions that violate this Code,
and may temporarily or permanently ban contributors for serious offenses.
The reporter is informed of the outcome.
